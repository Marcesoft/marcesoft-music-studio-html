# Marcesoft Music Studio

Uma versão web em HTML/JavaScript de um estúdio musical minimalista inspirado em DAWs modernos. O projeto permite criar faixas, ativar passos em um sequenciador, controlar BPM e reproduzir sons básicos em tempo real via Web Audio API.

## Funcionalidades

- Adicionar faixas com nome, tipo e cor
- Edição de pattern em 16 passos
- Play/Stop com controle de BPM
- Mixer visual
- Sons de kick, snare, hi-hat, bass, lead e pad
- Interface responsiva em HTML/CSS/JS

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Web Audio API

## Como rodar

1. Abra o arquivo `index.html` em um navegador, ou
2. Execute um servidor local:

```bash
python -m http.server 8000
```

Em seguida acesse:

```text
http://localhost:8000
```
